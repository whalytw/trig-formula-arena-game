# 三角公式挑戰：三人複習場

版本：1.0.0

一個可離線開啟、可放上 GitHub Pages 的高中數學四選一網頁遊戲。三位學生可在觸控白板的左、中、右區各自挑戰。內容依據本次提供的單元 1–4 課本，聚焦公式辨認、反向合併和適用條件。

## 開始使用

1. 解壓縮後，進入 `trig-formula-arena` 資料夾。
2. 用新版 Microsoft Edge 或 Google Chrome 開啟 `index.html`。請將其餘檔案留在同一個資料夾。
3. 老師按「教師設定」選擇單元、題數、時間。
4. 同學可選座號，也可以不填；各區按「開始挑戰」，或由老師按「三區一起開始」。
5. 點選一個選項即可送出。答對 +10 分，答錯或逾時 0 分。
6. 顯示正確選項與公式提醒後，自動換題；完成後顯示分數、正確率與各單元答對題數。
7. 某區完成時，可以直接選下一位同學的座號，再按「下一位同學開始」。另外兩區繼續原回合。

## 預設與可調整設定

| 設定 | 預設 | 可選值 |
| --- | --- | --- |
| 出題單元 | 單元 1–4 全選 | 可單選或複選 |
| 每人題數 | 12 題 | 4、8、12、16、20、24、30、40、60、80 |
| 每題時間 | 20 秒 | 不限時，或 10、15、20、25、30、40、60、90、120 秒 |
| 公式提醒停留 | 4 秒 | 2、4、6、8、10 秒 |
| 座號上限 | 30 號 | 30、35、40、45、50、60 號 |
| 畫面 | 深色 | 可切換淺色 |

所有單元平均抽題；預設 12 題會從每單元各抽 3 題。每區獨立洗牌題目及四個選項。同回合不重複題目；跨學生回合可能抽到相同公式。若所選單元的題數不足，設定畫面會要求降低每人題數。

設定與顏色模式儲存在目前瀏覽器。設定變更套用到之後開始的回合，正在作答的回合保留原設定。各回合分數保存在畫面上，重新整理頁面後清除。

## 題庫範圍

| 單元 | 題數 | 公式與觀念 |
| --- | --- | --- |
| 1 弧度量 | 16 | 弧度定義、度弳換算、同界角、扇形弧長與面積、常用特殊角 |
| 2 三角函數的圖形 | 22 | sin／cos／tan 的週期與值域、振幅、對稱、定義域、平移伸縮、最大最小值與頻率 |
| 3 三角的和差角公式 | 28 | 正弦／餘弦／正切和差角、反向辨認、二倍角、三倍角、半角與正負號、商數與平方關係、直線夾角及圓角 |
| 4 正餘弦的疊合 | 16 | 疊合形式、振幅與相位條件、最大最小值、週期、基本疊合、有限區間極值提醒 |
| 合計 | 82 | 每題均為四選一 |

以一般參數出現的題目，問的是普遍適用的公式。正切公式顯示定義條件，半角公式提醒正負號取決於半角的象限。全實數極值與限制區間極值分開處理。錯題複習列出對應課本的印刷頁碼。

## 觸控與教師操作

- 三區支援獨立 Pointer Events，同時作答不共用選取狀態。
- 「暫停」同時凍結作答時間與公式提醒的換題倒數。
- 開啟教師設定或錯題複習視窗會暫停三區；關閉後恢復開啟前的暫停狀態。
- 「三區一起開始」只啟動等待／完成的區域，不會重置正在進行的區域。
- 「鎖定操作列」隱藏教師按鈕，長按右上角 2 秒可解鎖。
- 「全螢幕」可透過瀏覽器全螢幕功能使用；若瀏覽器不允許按鈕進入，可按 F11。
- 桌面寬度達 1050 像素時三區並排；窄螢幕會改成三區上下排列。

操作列鎖定控制的是網頁內的按鈕。Windows 系統手勢、瀏覽器邊緣手勢及 ViewBoard 的 OSD 不由網頁控制。多人觸控是否完整傳至電腦，需在實際的 ViewBoard／AirSync 或有線觸控回傳連線上測試。

## 上傳 GitHub Pages

建議專案名稱：`trig-formula-arena`

1. 在 GitHub 建立一個 repository。一般免費帳號使用 Public repository 可開啟 GitHub Pages。
2. 在 repository 的檔案頁面，選 **Add file → Upload files**。
3. 將本資料夾內的 `index.html`、`styles.css`、`math.js`、`questions.js`、`app.js`、`README.md`、`使用說明.txt` 上傳到 repository 根目錄，再提交。不要只上傳壓縮檔，也不要將外層資料夾當成根目錄。
4. 進入 **Settings → Pages**。
5. 在 **Build and deployment → Source** 選 **Deploy from a branch**。
6. Branch 選 **main**，資料夾選 **/(root)**，按 **Save**。
7. 等部署完成後，Pages 頁面會顯示可開啟的網站網址。

入口 `index.html` 應直接出現在 repository 檔案頁面的根目錄。此專案不需要 npm 安裝、建置、資料庫或 API 金鑰。所有公式使用瀏覽器原生 MathML，沒有外部字型或 CDN 依賴。

GitHub 官方說明：
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 驗證紀錄

- JavaScript 語法、82 題四選一結構、選項文字不重複與 MathML 分數／次方節點檢查通過。
- 500 次模擬抽題確認預設各單元 3 題、同回合不重複，且每題保留一個正確選項。
- 使用模擬 DOM 驗證三區獨立作答、重複觸發防護、暫停／繼續、逾時、不限時、單區完成與換人重開。
- 此環境未能完成實際瀏覽器畫面與 IFP8653 多人觸控驗證。正式上課前可先用 4 題、10 秒的設定試玩一次。
